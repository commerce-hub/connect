Install

Configure GitHub Packages authentication without committing the token:

@commerce-hub:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_PACKAGES_TOKEN}

Install v0.13.4 from GitHub Packages:

npm install @commerce-hub/connect-wallet-sdk@0.13.4

Alternatively, install the package from the GitHub Release asset:

npm install https://github.com/commerce-hub/connect/releases/download/v0.13.4/commerce-hub-connect-wallet-sdk-0.13.4.tgz

The package registers the <commerce-hub-connect> custom element when imported.

import '@commerce-hub/connect-wallet-sdk';

Basic HTML

<commerce-hub-connect></commerce-hub-connect>

TypeScript

Use property assignment for complex values such as interactionResponse and designConfig.


import '@commerce-hub/connect-wallet-sdk';
import type {DesignConfig, InteractionResponse} from '@commerce-hub/connect-wallet-sdk';

const interactionResponse: InteractionResponse =
  await fetch('/api/commercehub/interaction').then((response) =>
    response.json()
  );
const designConfig: DesignConfig = {
  colors: {
    primary: '#084acc',
    text: '#101828',
    border: '#cbd5e1',
    widgetBackground: '#ffffff',
  },
};

const widget = document.querySelector('commerce-hub-connect');

if (widget) {
  widget.interactionResponse = interactionResponse;
  widget.designConfig = designConfig;
  widget.baseURL = 'QA';
}

The assigned InteractionResponse only bootstraps the widget with interactionId and optional gateway OAuth. The SDK calls GET /interaction when that id is assigned and renders saved or selected payment methods from the server-fetched interaction state, not from host-provided paymentSources.

The interaction response supplied to the widget must include the OAuth values returned for that interaction. If the Create Interaction integration returns client_id and configuration_id separately, add them under interactionResponse.oauth before assigning the response. The value passed to the widget should have this shape:

{
  "interactionId": "...",
  "oauth": {
    "client_id": "...",
    "configuration_id": "...",
    "access_token": "...",
    "token_type": "Bearer"
  }
}

Frameworks

The SDK is framework-agnostic. In React, Vue, Svelte, Angular, or Lit, import the package once and pass complex values as DOM properties rather than HTML attributes. This applies to interactionResponse and designConfig; object values should not be serialized into markup.

See the Lit example, React example, Angular 22 example, and plain JavaScript example for components that bind SDK properties and keep merchant completion host-owned after onSelect.


widget.interactionResponse = interactionResponse;
widget.designConfig = designConfig;

Only base-url is available as a string attribute:

<commerce-hub-connect base-url="QA"></commerce-hub-connect>
