# GitHub v0.12.3 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release the `dc666e7` SDK behavior as unscoped package `connect-wallet-sdk` version `0.12.3` through a GitHub Release asset without publishing to a package registry.

**Architecture:** Prepare an isolated release branch/worktree rooted at `dc666e7` so later SDK behavior is excluded by construction. Change only package identity metadata and its package-surface assertion, build and pack the artifact, then tag the verified release commit and attach the tarball to a published GitHub Release.

**Tech Stack:** Git, npm, Node.js test runner, TypeScript, GitHub CLI
