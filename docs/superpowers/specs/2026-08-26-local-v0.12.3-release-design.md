# GitHub v0.12.3 release

## Objective

Create `connect-wallet-sdk` version `0.12.3`, publish it as a GitHub Release asset, and do not publish it to any package registry.

## Baseline

The packaged SDK source and behavior must match commit `dc666e7`, the version `0.12.2` baseline. Later source changes are excluded from this release.

## Allowed differences

- Set the package name to `connect-wallet-sdk`.
- Set the package version to `0.12.3`.
- Remove GitHub Packages publishing metadata because this release is distributed as a GitHub Release asset.
- Update lockfile package metadata and package-surface expectations to match the new identity.

## Constraints

- Do not publish to npm, GitHub Packages, or any other package registry.
- Do not introduce or modify PBB behavior relative to `dc666e7`.
- Preserve the unrelated untracked `INTERNAL_GITHUB_PACKAGES_INSTALLATION.md` file.
- Create and push the `v0.12.3` Git tag.
- Create a published GitHub Release for `v0.12.3` and attach `connect-wallet-sdk-0.12.3.tgz`.

## Verification

- Confirm tracked SDK behavior matches `dc666e7`, excluding approved package metadata and release verification files.
- Run package-surface tests and the production build.
- Run `npm pack` locally and inspect the generated tarball metadata and contents.
- Confirm the remote tag and published GitHub Release point to the intended release commit and contain the tarball asset.
