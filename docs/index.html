<commerce-hub-connect>

<commerce-hub-connect> is the public Web SDK widget shell. The first SDK slice ships internal primitives that match the CommerceHub Connect Figma source of truth and can later be composed into the full payment-method flow.

Basic usage

<commerce-hub-connect></commerce-hub-connect>

Theming

Host applications can override the SDK defaults with CSS custom properties.

commerce-hub-connect {
  --chc-primary: #084acc;
  --chc-text: #101828;
  --chc-border: #cbd5e1;
}
