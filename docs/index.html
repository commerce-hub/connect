<commerce-hub-connect>

<commerce-hub-connect> is the public Web SDK widget shell. The first SDK flow slice renders OTP verification, saved payment-method selection, and the no-saved-payment-methods variant.

Basic usage

<commerce-hub-connect></commerce-hub-connect>

Interaction calls

Hosts pass an InteractionResponse into .interactionResponse. When the SDK handles OTP validation, OTP resend, or saved payment-source attach actions, it uses interactionResponse.interactionId as the x-interaction-id header. If interactionId is missing, the widget does not call the CommerceHub API and keeps the current screen stable. This flow slice does not emit onSuccess or onError events.

Design configuration

Host applications can pass an optional .designConfig object to override merchant-safe colors, the base text size, and current screen copy. The object and all nested fields are optional.


html`<commerce-hub-connect
  .interactionResponse=${interactionResponse}
  .designConfig=${{
    colors: {
      primary: '#084acc',
      text: '#101828',
      border: '#cbd5e1',
    },
    baseFontSize: '16px',
    copy: {
      otp: {
        title: 'Confirm your email',
        verifyButton: 'Confirm code',
      },
      paymentMethods: {
        title: 'Choose payment',
        continueButton: 'Use selected method',
      },
    },
  }}
></commerce-hub-connect>`;
