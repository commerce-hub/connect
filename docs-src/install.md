# Install

The package is currently private while the SDK widget API is taking shape.

## Local development

```bash
npm i
npm run build
```

Import the component module and render the public element.

```html
<script type="module" src="./commerce-hub-connect.js"></script>
<commerce-hub-connect></commerce-hub-connect>
```
