Browser SDK demo

Hosted checkout browser demo

This page lives outside the Angular workspace and invokes the browser SDK loader, which mounts an Angular-hosted checkout inside an iframe. The flow still uses the hosted checkout endpoints from session-controller and interaction-controller through a local same-origin proxy.
