# Security Policy

## Reporting a Vulnerability

Do not open public issues for suspected vulnerabilities, exposed credentials,
or customer-sensitive data. Report security concerns through the owning
CommerceHub/Fiserv security process for this repository.

Include the affected version or commit, reproduction steps, and the minimum
details needed to assess impact. Avoid sharing real merchant credentials,
merchant tokens, customer data, payment credentials, or production request
payloads.

## Sensitive Data

This repository must not contain secrets, merchant tokens, real customer data,
or private registry credentials. Local development credentials should be
provided through environment variables and kept out of git.
