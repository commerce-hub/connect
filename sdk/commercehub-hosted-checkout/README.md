# CommercehubHostedCheckout

Angular library package for the CommerceHub Connect hosted checkout.

## Build

```bash
ng build commercehub-hosted-checkout
```

The package output is written to `dist/commercehub-hosted-checkout`.

## Test

```bash
ng test commercehub-hosted-checkout --watch=false
```

## Publish

After building, publish from `dist/commercehub-hosted-checkout` with your normal npm workflow.
